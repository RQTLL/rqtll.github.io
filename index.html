ROS2 QT LAYER FOR LOW-LEVEL OPERATIONS

Ecosistema RQTLL Listo para ROS 2

RQTLL combina un cliente PySide6 con backend en Rust para ofrecerte control, telemetría y compilación asíncrona de ROS 2 en un solo lugar.

Instalación Simple

Instala RQTLL en tu sistema con un solo comando.

RQTLL se instala en cualquier derivada de Ubuntu compatible con ROS 2. Ejecuta el siguiente comando en tu terminal para instalar RQTLL y sus dependencias. El comando descarga un script de instalación desde el repositorio de RQTLL y lo ejecuta con permisos de superusuario. Puedes revisar el script antes de ejecutarlo en rqtll-distro.

bash - install
>_ sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/RQTLL/rqtll-distro/main/install.sh)"

Sistema recomendado

  • Distribución: Ubuntu 22.04 LTS x86_64 o superior
  • Configuración del sistema: Paquete de idioma configurado en UTF-8
  • Paquetes: curl git
  • Manejador de ventanas: Wayland

Notas importantes

  • El script de instalación requiere permisos de superusuario para instalar dependencias y configurar el sistema.
  • El script está diseñado para sistemas basados en Ubuntu, puede fallar en otras distribuciones de Linux.
  • Revisa el script antes de ejecutarlo para asegurarte de que cumple con tus necesidades y políticas de seguridad.
